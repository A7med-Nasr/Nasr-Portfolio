# Nasr Portfolio Website

A personal portfolio website for **Ahmed Nasr**, a Frontend Developer and UI/UX Designer based in Egypt.

🔗 **Live site:** https://a7med-nasr.github.io/Nasr-Portfolio/

## About the Website

This is a single-page portfolio site that showcases:

- **About Me:** Introduction to Ahmed Nasr, his background, education, and work experience.
- **Skills:** HTML, CSS, JavaScript, Angular, Figma, in addition to drawing skills (pencil, white coal, color painting).
- **Experience:** Frontend Developer for over 2 years, UI/UX Designer for over 1 year, and an artist for more than 5 years.
- **Projects:** A gallery featuring 15+ completed projects, including e-commerce sites, dashboards, landing pages, and UI/UX designs, each with a demo link.
- **Services:** An overview of the web development and UI/UX design services offered.
- **Testimonials:** A section showing client feedback (sample/placeholder testimonials).
- **Contact:** A contact form along with social media links (LinkedIn, Facebook, Instagram, GitHub, X).

## Technologies Used

The website is built with **HTML, CSS, and JavaScript**, featuring a fully responsive design that works well on mobile, tablet, and desktop screens.
